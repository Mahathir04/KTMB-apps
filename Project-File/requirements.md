# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow users to search for train schedules by selecting their departure station, destination station, and travel date.
2. The system shall display train schedules, departure times, arrival times, ticket prices, and seat availability in an organized layout.
3. The system shall provide a simplified ticket booking process with clear instructions at each booking stage.
4. The system shall allow users to view their booking history and access their purchased e-tickets easily.
5. The system shall provide clear booking and payment confirmation messages after a successful transaction.

## Non-functional requirements (how the system must PERFORM)
1. The system shall load the main interface and display search results within 3 seconds under normal network conditions.
2. The system shall provide a responsive interface that adapts to different screen sizes, including smartphones and tablets.
3. The system shall use readable fonts, consistent colours, and clear navigation elements to ensure a user-friendly experience.
