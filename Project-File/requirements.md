# Requirements

## Functional Requirements (What the system must DO)

**FR1:** The system shall allow users to search for train schedules by selecting their departure station, destination station, and travel date.

**FR2:** The system shall display train schedules, departure times, arrival times, ticket prices, and seat availability in an organized layout.

**FR3:** The system shall provide a simplified ticket booking process with clear instructions at each booking stage.

**FR4:** The system shall allow users to view their booking history and access their purchased e-tickets easily.

**FR5:** The system shall provide clear booking and payment confirmation messages after a successful transaction.

## Non-Functional Requirements (How the system must PERFORM)

**NFR1:** The system shall load the main interface and display search results within 3 seconds under normal network conditions.

**NFR2:** The system shall provide a responsive interface that adapts to different screen sizes, including smartphones and tablets.

**NFR3:** The system shall use readable fonts, consistent colours, and clear navigation elements to ensure a user-friendly experience.
