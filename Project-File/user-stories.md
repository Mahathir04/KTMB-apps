# User Stories

1. As a KTMB passenger, I want to navigate the application easily, so that I can find important features such as train schedules and ticket bookings without confusion.
   Acceptance criteria:
  1. The application must display clearly labelled navigation menus for important features such as train schedules, ticket booking, and booking history.
  2. Users must be able to access the train schedule and ticket booking pages directly through the main navigation menu.

2. As a first-time user, I want a simple and step-by-step ticket booking process, so that I can purchase train tickets without difficulty.
   Acceptance criteria:
  1. The application must guide users through the ticket booking process in clear steps, including selecting departure and arrival stations, travel dates, and train schedules.
  2. The application must display a booking summary containing the selected journey details before users confirm their booking.

3. As a frequent commuter, I want to view my booking history and e-tickets easily, so that I can access my travel information quickly without repeating the booking process.
   Acceptance criteria:
  1. The application must provide a dedicated booking history section where users can view their previous and upcoming bookings.
  2. Users must be able to access and view their e-tickets directly from the booking details page without having to repeat the booking process.
